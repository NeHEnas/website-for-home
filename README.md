# website-for-home

html, css, js, php, sql


Веб-интерфейс для домашнего использования, быстрого доступа к локальным сервисам, дашборд мониторинг, красивые виджеты быстрого доступа.
Адаптивность для телефонов и ПК.
Смена на светлую и темную темы(подобно к стилистике дискорда) и переключение.

Главная страница:
Приветсвие(отличается в зависимости от времени. Утро, день, вечер) , вывод температуры дома и на улице.
Поиск в правом верхнем углу
Виджеты для удобной навигации
